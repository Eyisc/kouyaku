不好意思，我在用翻譯 App，可以請你對著手機慢慢說嗎？

  1. 下方切換語言：中⇄日、中⇄英、英⇄日。
  2. 按 我說：講中文，翻成日文並唸出來。
  3. 按 對方說：對方講日文，翻成中文。
  4. 講完停一下會自動停止，也可以再按一次停止。
  5. 閒置 2 分鐘自動斷線，不會一直計費。
  6. 聽導覽或廣播時切到 聆聽，會一直翻下去。

第一次使用：貼上 OpenAI API 金鑰

  1. 到 platform.openai.com/api-keys 建立一把金鑰（帳號要先儲值）。
  2. 建議另開一個專案給這個 App，並設定每月預算上限。
  3. 把 sk- 開頭的金鑰貼到下面。

金鑰只存在這支手機裡，只會送到 api.openai.com。
